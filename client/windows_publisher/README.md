# TOTOD Windows 本地发布客户端

客户端在用户自己的 Windows 电脑上打开可见的 Microsoft Edge，通过本机常用网络发布知乎回答。每个知乎账号使用独立浏览器资料目录，不共享 Cookie。

## 使用步骤

1. 在 TOTOD 后台进入“任务与系统 → 本地发布客户端”，绑定电脑并复制一次性设备密钥。
2. 下载 GitHub Actions 中最新的 `TOTOD-Windows-Publisher` 构建产物并解压运行。
3. 填写 `https://totod.cn` 和设备密钥，点击“保存并连接”。
4. 到 TOTOD 的知乎账号编辑页，将回答发布方式设为“Windows 本地客户端”。
5. 在客户端选择 qwg2，点击“登录所选账号”，在打开的 Edge 中完成知乎登录。
6. 保持 Edge 和客户端运行，点击“开始监听发布任务”，再从 TOTOD 创建回答发布任务。

客户端不会绕过验证码或平台风控。知乎出现安全验证时，请在可见 Edge 窗口中人工完成。

## 本机开发构建

安装 Python 3.12 后双击 `build.bat`。可执行文件输出到 `dist` 目录。
